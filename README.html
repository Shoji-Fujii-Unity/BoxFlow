BoxFlowv2.0

サーバー不要・単一HTMLファイルの倉庫番風パズルゲーム。スマホ（縦長）主体・PC対応。v2.0で全30面・レベル選択・★評価・パー導入。

特徴

  • 📱 スマホ主体の縦長レイアウト（safe-area対応）/ PCキーボード対応
  • 🎮 スワイプ / 十字ボタン / 矢印・WASD の3系統入力
  • 🗂 レベルセレクション（30面グリッド：ロック／クリア／★／ベスト手数。Lキーでも開閉）
  • ⭐ ★評価とパー（目標手数）：全面にA*検証済みのパーを設定
  • 🧩 全30面の段階的難易度（v1.6の20面を全継承＋新11面＋刷新1面）。↩待避 / 🔄やり直し
  • ✨ 箱とプレイヤーのスライドアニメーション、クリア時コンフェティ、バイブ（対応端末）
  • 🔤 Google Fonts（Outfit / Zen Maru Gothic）— 唯一の外部参照。オフライン時はシステムフォールバック
  • 🔊 サウンド ON/OFF（Web Audio API 合成音）／ 🌐 多言語（ja / en / zh）
  • 💾 localStorage 自動保存（v2形式、旧 v1 からの自動マイグレーション付き）
  • ⚖️ 実行時の依存ライブラリ・ビルド工程ゼロ（tools/ は開発用）

起動方法

index.html をブラウザで開くだけ（file:// OK・オフライン可）。静的ホスティングにもそのまま配置できます。

遊び方

箱を全ゴールに置いたらクリア。倉庫番ルール準拠（引けない／2個押せない／壁・盤外・箱の先へは動かせない）。

セーブデータ

キー boxflow_save_v2（localStorage）。面ごとに done / best / stars / state、全体で lang / sound / next。旧 20面構成の boxflow_save_v1 からは自動マイグレーション（クリア・ベストは対応する新面へ、中断位置はレイアウト不変の面のみ復元）。初期化は開発者ツールから当該キーを削除。

技術メモ

  • 単一HTML（HTML+CSS+Vanilla JS）。静的タイル＋絶対配置スプライトでスライドアニメを実現
  • レベル定義: 行文字列配列（#壁 .ゴール $箱 @PL 空白=床）。編集は tools/levels-data.mjs → node tools/build-levels.mjs で index.html に注入
  • tools/（開発用）: solver.mjs＝push最適A*（押距離×ハガリー割当ヒューリスティック、角フリーズ・2×2袋小路枝刈り）／build-levels.mjs＝全面検証とパー注入／gen-level.mjs＝pull逆向き生成（解保証面）／par-cache.json＝検証結果
  • フォントは Google Fonts CDN を参照（唯一の外部依存）。不通時はシステムフォールバックで遊技継続可
  • サウンドは初回ユーザー操作で AudioContext をアンロック（自動再生ポリシー準拠、初回タップのみ無音の場合あり）。対応端末では操作・クリア時にバイブ

Save data

Key boxflow_save_v2 in localStorage; per level done / best / stars / state, global lang / sound / next. Auto-migrates from the 20-level boxflow_save_v1 (clears & bests remap; in-progress states restored only where the layout is unchanged). Delete the key to reset.

Tech notes

  • Single HTML file; static tiles + absolutely positioned sprites give the sliding animation
  • Levels are row strings (# wall, . goal, $ box, @ player). Edit tools/levels-data.mjs, then run node tools/build-levels.mjs to inject verified pars into index.html
  • tools/ (dev-only): solver.mjs — push-optimal A* (push-distance × Hungarian assignment heuristic; corner-freeze and 2×2-block deadlock pruning) / build-levels.mjs — verify & inject / gen-level.mjs — reverse-pull generator (solvable by construction) / par-cache.json — results
  • Fonts via Google Fonts CDN (the only external dependency); system fallback keeps the game playable offline
  • AudioContext unlocked on first user gesture; vibration on supported devices

技术说明

  • 单个 HTML；静态地块＋绝对定位精灵实现滑动动画
  • 关卡为行字符串（#墙 .目标 $箱 @玩家）：改 tools/levels-data.mjs 后运行 node tools/build-levels.mjs 注入验证过的 par
  • tools/（仅开发用）：solver.mjs＝最优推数 A*（推距×匈牙利指派启发式，角冻结与 2×2 死锁剪枝）／build-levels.mjs＝验证与注入／gen-level.mjs＝逆向拉箱生成（构造性可解）／par-cache.json＝结果
  • 字体引用 Google Fonts CDN（唯一外部依赖），不可达时回退系统字体
  • 首次操作解锁 AudioContext；支持的设备会震动
